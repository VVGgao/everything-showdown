# 音乐歌池与 64 强抽签设计

## 目标

把嘻哈厂牌和 K-pop 团体从展示目录升级为可选歌池。用户可以组合多个歌池抽取 64 首歌曲，也可以从整个音乐赛区直接抽取 64 首，随后沿用单败淘汰赛完成 63 场选择。

## 数据

- 曲库由本地生成脚本从网易云搜索结果构建，成品页面不依赖实时搜索接口。
- 嘻哈以厂牌/说唱团体为歌池，K-pop 以偶像组合为歌池。
- 每条歌曲保存稳定 ID、歌名、艺人、年份、歌池、厂牌和网易云封面 URL。
- 搜索结果去重，不虚构新团体没有的作品；歌池数量真实显示。

## 交互

- 音乐赛区显示可多选的歌池目录和当前可用歌曲数。
- “从所选歌池抽取 64 首”在去重后不足 64 首时禁用，并明确提示还差多少首。
- “全赛区随机 64 首”从当前赛区完整曲库抽签。
- 新抽签会清空当前赛程，64 首固定为本次签表；进度和签表保存在浏览器。
- 游戏赛区保持现有 32 强，自定义赛事保持现有 2–32 项能力。

## 界面

新增一块赛前选队席：紧凑的厂牌/团体清单、选中状态、曲库计数和两个明确动作。它使用现有编辑式排版、细分隔线和主题强调色，不做圆角仪表盘卡片。

## 验证

- 纯函数测试覆盖多歌池合并、去重、64 首抽取、曲库不足和 64 强 63 场结束。
- 服务端渲染测试覆盖歌池选择器及两个抽签入口。
- 构建成功，并检查曲库总量、每个歌池计数和封面字段。
