# Everything Showdown

一个让歌曲、游戏和任何值得争论的内容进行淘汰赛对决的平台。当前版本包含中国嘻哈、K-POP 与游戏三个官方赛区，并提供 64 强签表、冠军统计、歌曲试听和“从夯到拉”拖拽锐评。

**在线体验：** [wanwu-showdown-2026.wayne-vvg-gao.chatgpt.site](https://wanwu-showdown-2026.wayne-vvg-gao.chatgpt.site)

## 主要功能

- 中国嘻哈、K-POP、游戏三个赛区共用一套淘汰赛赛制
- 音乐赛区支持 64 强，游戏赛区支持 32 强
- 按厂牌或团体选择曲库，也可从全赛区热门优先抽取
- 首轮尽可能安排不同厂牌或团体之间的对决
- 嘻哈曲库按厂牌和个人细分，K-POP 曲库按团体组合分类
- 歌曲封面、官方播放链接，以及部分热门歌曲试听片段
- 本地保存赛事进度、冠军结果和自定义比赛
- 匿名冠军选择统计 Demo
- 随机抽取 10 首歌曲进行“夯、顶级、人上人、NPC、拉完了”拖拽锐评
- 手机端采用六页底部导航，减少长页面连续滚动

## 开发历程

项目最初是一个中国嘻哈歌曲二选一 Demo，随后逐步演进为通用内容比赛平台：

1. 搭建嘻哈歌曲对决界面，完成基础晋级逻辑和视觉风格。
2. 抽象共用淘汰赛引擎，加入 K-POP 和游戏赛区。
3. 扩展到 64 强，增加厂牌、团体与个人曲库结构。
4. 加入热度偏置抽取和跨厂牌首轮配对，减少同阵营内战。
5. 整理曲目归属，补充封面、官方链接与试听片段。
6. 增加冠军统计、折叠曲库、拖拽锐评和手机分页导航。
7. 完成生产构建并公开上线。

## 技术实现

- React 19 + TypeScript
- vinext / Vite
- Cloudflare Workers 兼容构建
- 原生 HTML Drag and Drop，并提供手机端下拉选择作为备用操作
- `localStorage` 保存设备本地进度
- Node.js 内置测试运行器覆盖抽签、赛制、曲库分组和服务端渲染

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm test
```

## 项目结构

```text
app/
  page.tsx              主页面与交互组件
  competition-data.ts   官方赛区与参赛内容
  music-catalog.json    嘻哈与 K-POP 完整曲库
  music-draw.js         热度抽取与跨厂牌配对
  tournament.js         通用淘汰赛逻辑
  roster.js             厂牌、团体和个人分组
  song-rating.js        锐评抽取与移动逻辑
public/covers/          歌曲封面与游戏图标
tests/                  自动化测试
```

## 数据说明

当前冠军人数为界面演示数据，不代表真实用户统计。音乐封面、试听和跳转链接用于作品展示与来源访问；完整音频不托管在本项目中。
